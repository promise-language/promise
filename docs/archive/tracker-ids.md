# Tracker IDs and the issues they became

Until 2026-10-03 this project kept its work items in a tracker whose IDs read `T0001` (task), `B0001` (bug) and `D0001` (deferred). Code comments, commit messages and documents across this repository cite those IDs. On that day the items still open were filed as GitHub issues, which is where work is tracked now.

This table says which issue each ID became, so a citation can still be followed. Each migrated issue also carries its tracker ID in the body, so searching the issues for an ID finds it too.

**An ID that is not listed has no issue.** It was closed before the migration — done, a duplicate, or declined — or was one of a handful not carried over to this repository, and what it recorded is in the history of the code that cites it.
